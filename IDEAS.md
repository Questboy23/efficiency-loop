# Efficiency Loop: ideas (dated public record)

Author: Goyim. First published: 2026-10-09. License: MIT.

The ideas below are released openly so anyone, including AI labs, can use them. This file is a dated record of authorship.

## Six modules
1. **Intake:** step-0 checklist of requirements, usage-limit quote, stakes-scaled thinking, goal downgrades, specialist routing, comparative-advantage allocation of expensive-model quota (half-Kelly sizing).
2. **Run monitor:** progress rate per token, semantic head-banging detection (same hypothesis failing repeatedly), pulse checks, zoom and reframe ladder ("10x instead of 10%"), escalation ladder, intervention bandit, staged budgets and runway framing, motivation framings, guarded lies with detection measurement.
3. **Verification:** fresh reviewer that sees only the prompt, checklist, and diff; meta-labeling of verification effort; adversarial bug agent; calibrated confidence; deferred scoring; structural bias fixes.
4. **Parallel search:** uncorrelated forks, staged funding of approaches, clone-and-cull, Coase rule for subagents.
5. **Learning loop:** self-improving overseer, budget tournaments with a budget ratchet, distribution analysis of runs, prompt optimizer, evolved specialists with partial pooling, shared failure memory, learn-from-reverts, blast-radius map, deletion agent.
6. **Measurement:** deflated scores, purged time-split tests, paired comparisons, cost factor model, execution scheduling across usage windows.

## Key claims to test
- A capped "10x review" follows a Laffer curve: some helps, too much hurts. The peak depends on task difficulty.
- Reframe nudges at stalls beat content-free nudges ("Wait"), which beat no nudge.
- A cheap model with this loop can match an expensive model alone at lower cost.
